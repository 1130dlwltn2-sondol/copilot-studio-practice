# 부록. 용어집

- 앱: 사람이 보고 입력하는 화면.
- 워크플로: 정해진 순서대로 실행되는 자동화. 에이전트 플로우라고도 한다.
- 에이전트: 상황을 보고 판단하는 AI.
- 미리보기: 정식 출시 전 공개된 기능.
- GA: 정식 출시.
- 순차 배포: 지역과 테넌트마다 기능이 나타나는 시점이 다른 것.
- 테넌트: 회사의 Microsoft 365 공간 단위.
- 환경: 테넌트 안에서 데이터를 나누어 담는 공간.
- 트리거: 흐름을 시작하는 사건.
- 액션: 실행되는 동작.
- Hooks: 에이전트 실행 중 특정 시점에 정해진 로직을 끼워 넣는 기능.
- Review 패널: 게시 전 막히는 점과 경고를 보여주는 화면.
- 평가: 정해진 테스트로 성능을 재는 일.
- 폴백: AI가 확신이 없을 때 사람에게 넘기는 것.
- Agent Author: 환경 안에서 에이전트를 만들 수 있는 역할.
- Dataverse: 데이터를 저장하는 공간.
