# 구매요청 미니 시스템 — 프로젝트

## 목표

가상의 구매 요청 업무를 앱·워크플로·AI 예외 처리·사람 승인으로 나누어 설계하고, 테스트로 검증하는 미니 시스템을 종이 설계로 완성한다.

## 입력 자료

- 가상 구매 요청 CSV (4장 실습)
- 3화면 와이어프레임 (5장 실습)
- 역할 나누기 표 (6장 실습)
- 테스트 10건 (7장 실습)
- 환경 확인표 (2장 실습)

모든 자료는 가상의 것이다. 실제 개인정보·계정·금액을 쓰지 않았다.

## 재현 절차

1. 1장 실습으로 업무를 세 영역에 나눈다.
2. 2장 확인표로 환경을 점검한다.
3. 3장 흐름도를 그리고 4장 명세서를 쓴다.
4. 5장 와이어프레임을 그린다.
5. 6장 역할 나누기를 정한다.
6. 7장 테스트 10건을 만든다.
7. 8장에서 설계서와 테스트 보고서를 묶는다.
