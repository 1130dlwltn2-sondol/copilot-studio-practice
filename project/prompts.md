# 사용한 프롬프트와 버전

기준일: 2026-10-11. 아래 프롬프트는 이 책의 각 장에서 쓴 복사용 프롬프트다.

1. 1장: 구매 요청 업무를 앱 화면, 규칙형 워크플로, AI 판단이 필요한 예외 처리로 분해해줘.
2. 2장: Copilot Studio 사용 전 계정, 테넌트, 역할, 라이선스, 평가 환경 만료일을 점검할 표를 작성해줘.
3. 3장: 요청 접수→금액 검증→승인→기록 순서를 조건 분기와 예외 처리까지 포함한 텍스트 흐름도로 표현해줘.
4. 4장: 가상 구매요청 CSV를 받으면 금액과 필수 필드를 검증하고 오류 항목은 보류하는 워크플로 명세서를 작성해줘.
5. 5장: 구매 요청 앱의 입력 화면, 검토 화면, 처리 결과 화면을 텍스트 와이어프레임으로 설계해줘.
6. 6장: 금액·날짜는 규칙으로 처리하고 설명문 분류만 AI가 맡도록 역할을 나눠줘. 불확실하면 사람에게 넘겨줘.
7. 7장: 정상/누락/고액/중복/민감정보 사례 10개를 만들고 승인 필요 조건과 실패 판정 기준을 써줘.
8. 8장: 앞선 결과를 모아 앱 화면, 워크플로, AI 예외 처리, 사람 승인, 테스트 케이스, 비용·권한 체크표를 포함한 프로젝트 문서를 만들어줘.
