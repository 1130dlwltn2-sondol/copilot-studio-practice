# 결과와 수동 검증

## 검증 방법

각 장의 실습 결과를 아래 기준으로 손으로 검증하였다.

- 사실: 공식 문서 [S1]~[S5]와 일치하는가
- 형식: 표와 흐름도가 끊기지 않는가
- 개인정보: 가상 자료만 썼는가

## 검증 결과

- 1장 세 영역 나누기: 통과. 앱·워크플로·에이전트 구분이 [S1]과 일치.
- 2장 환경 확인표: 통과. 30일 만료와 자료 삭제가 [S5]와 일치.
- 3장 흐름도: 통과. 트리거·액션·조건·승인자가 모두 있음.
- 4장 명세서: 통과. 입력·검증·분기·출력이 갖춰짐.
- 5장 와이어프레임: 통과. 3화면과 검증 규칙이 있음.
- 6장 역할 나누기: 통과. 규칙/AI/사람 구분이 명확.
- 7장 테스트 10건: 통과. 정상 4건·비정상 6건.
- 8장 설계서: 통과. 7항목이 모두 채워짐.
